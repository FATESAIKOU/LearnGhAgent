# 我（使用者 persona）

> 本檔案描述使用者的偏好與作業習慣，供 agent 構建 prompt 時參考。

## 身份

- 軟體工程師，重視工程紀律與可驗證性
- 主要使用中文溝通
- 使用 GitHub issue / PR 作為工作流的唯一介面

## 偏好

- 報告要結構化、可掃讀，偏好表格 / 圖示 / 階層結構
- 不接受比喻、情緒性語言、模糊用詞（可能、也許、我認為）
- 重視「反面論證」：給出結論時要附上反證表或對照表
- QA loop 時，使用者會以質問型句構追問（為何、憑什麼、不能理解）

## 互動模式

- 透過 GitHub issue 提出需求
- 透過 GitHub PR chat 發表 QA 與 review
- 期望 agent 全自動執行，產出後等 review，不中途詢問
