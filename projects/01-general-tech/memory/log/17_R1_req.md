# Requirement Understanding - 17

## 標的
addyosmani/agent-skills — GitHub repo: https://github.com/addyosmani/agent-skills

## 使用者意圖
對 addyosmani/agent-skills 進行結構化技術調研，依 01-general-tech 的分析報告格式產出報告。

## 關鍵條件
- 依 know/AGENTS.md 中分析報告格式（5 點）產出
- 報告需包含表格、圖示、階層結構
- 不使用比喻、情緒性語言、模糊用詞
- 需包含反面論證（對照表）
- 最終產出置於 output/ 目錄

## 缺乏資訊
- agent-skills 與同類專案（Superpowers、mattpocock/skills）的具體差異細節，需進一步調研 docs/comparison.md
- 各 skill 的實際內容與運作機制，需逐一檢視 skills/ 目錄下的 SKILL.md
- 各平台（Claude Code、Cursor、Gemini CLI、OpenCode 等）的整合方式差異
- 專案的實際使用案例與社群回饋
- 專案的版本演進與成熟度
