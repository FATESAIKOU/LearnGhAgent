## 問題點

## 建議

1. 在「狀況理解」或「執行的動作與結果」中，補充具體的資訊取得方向，例如：
   - 查閱 anthropics/courses 的 GitHub README 以確認組織身份與課程範圍
   - 查閱 anthropics 官方網站以確認業務定位
