# Step 3 - 品質保證 Review 觀點

> 軟性驗證 Step 3 品質報告產出時，LLM 應採用的 review 觀點。

## 驗證項目

| 項目 | 結果 | 備註 |
|------|------|------|

1. **5 個 section 齊全**：§1 檢查摘要、§2 ESLint、§3 Prettier、§4 TS、§5 覆蓋率 是否都存在？
2. **數據正確性**：報告中的數字（錯誤數、覆蓋率百分比）是否與實際檢查結果一致？
3. **語言合規**：是否使用中文？是否避免比喻、情緒性語言、模糊用詞？
4. **結構化呈現**：是否使用表格呈現檢查結果？
5. **嚴重問題標記**：是否標記了嚴重違規或低覆蓋率模組？
6. **報告檔名**：是否符合 `(pr-id)_(round-id)_quality-report.md` 格式？長度是否在限制內？
