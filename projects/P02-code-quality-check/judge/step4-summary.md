# Step 4 - 總結 Review 觀點

> 軟性驗證 Step 4 summary 產出時，LLM 應採用的 review 觀點。

## 驗證項目

| 項目 | 結果 | 備註 |
|------|------|------|

1. **本輪產出列舉完整**：是否列出本輪所有產出檔案（報告 + 所有 step log）？
2. **變更摘要準確**：是否說清本輪做了哪些檢查及其結果？
3. **待追問合理性**：預期使用者可能追問的方向是否合理（如特定違規細節、修復建議）？是否無則寫「無」？
4. **log 格式合規**：4 個 section 是否齊全且順序正確？長度是否在限制內？
