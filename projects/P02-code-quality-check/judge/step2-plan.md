# Step 2 - 執行計劃 Review 觀點

> 軟性驗證 Step 2 各 sub-step（C1, C2...）產出時，LLM 應採用的 review 觀點。

## 驗證項目

| 項目 | 結果 | 備註 |
|------|------|------|

1. **檢查工具選擇適切性**：是否根據專案設定檔正確選擇要執行的檢查工具？
2. **命令正確性**：執行的檢查命令是否正確（參數、路徑、忽略規則）？
3. **結果完整性**：是否涵蓋所有適用的檢查項目？是否有遺漏的檢查？
4. **錯誤處理**：當檢查工具不存在或執行失敗時，是否有適當的 fallback 或註記？
5. **log 格式合規**：4 個 section 是否齊全且順序正確？長度是否在限制內？
