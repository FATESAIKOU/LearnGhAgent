# 133_R2_step1-intent.md

## 狀況理解

R2 為使用者追問。使用者提出兩個具體問題：

1. **cache_control 是什麼**：要求說明其定義、解決的問題、問題背景、解決機制、提出者
2. **導入 pxpipe 前後的 prompt 形狀**：要求針對各種場景舉例，展示導入 pxpipe 前後傳送給 LLM API 的完整 prompt 差異，最後總結

這兩個問題都屬於 R1 報告中已提及但未深入展開的面向。cache_control 在 R1 報告 §3.3 有簡述（快取對齊機制），但未說明其本質。prompt 形狀則完全未在 R1 報告中展示。
