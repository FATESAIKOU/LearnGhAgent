## 狀況理解

R1（PR body 即第一次發言）。使用者貼出技術標的：**MiniMax-H3**，描述為「MiniMax 開源的全模态音视频生成模型」，並附一個 GitHub 連結（issue 標籤誤標為 HuggingFace，實際是 `https://github.com/MiniMax-AI/MiniMax-H3`）。`Closes #204` 表示此調研即原始 issue 需求本身。

依 workflow，本次任務為「技術解析助理」對該標的執行結構化調研並產出分析報告（含 4 大 section + User Q&A）。Step 1 只需定調意圖，不產出報告。

技術標的判定：**MiniMax-H3**（MiniMax 開源的全模態音視頻生成模型）。無額外附帶條件。
