# 282_R2_step1-intent.md

## 狀況理解

- 本輪（R2）為**追問輪**，非新主題。使用者針對 R1 報告 `output/282_laya.md` 提出 5 個追問，屬「界定與判準」型，無新增調研標的。
- 5 問分兩類：
  - **界定類（Q1–Q4）**：Laya 的產品邊界（一個模型 vs 一組內含模型的軟體）、成本結構（有無雲端付費部分）、與 Jev 的關係（包裝 Jev 還是「Jev 沒開源→做本地複製版＋順帶配軟體框架」）、「效能不好」的語意（是否指判斷品質）。
  - **判準類（Q5）**：該從 Laya 借哪一層機制——**模型架構／訓練手法** vs **外層系統架構**；並附質疑「模型架構與訓練手法若沒有廣泛驗證，也沒必要學」。
- **意圖定調**：使用者要的不是再一輪調研，而是把 R1 報告中**未說清或易誤解的邊界講死**（Q1–Q4），並取得一個**是否值得學、學哪一層的判準**（Q5）。Q5 帶「憑什麼／沒必要學吧」質問句構，觸發 QA。
- **輸出落點**：本輪須在 `output/282_laya.md` 追加 `## 5. User Q&A`，5 子問題拆成 5 個獨立 QA（AGENTS.md：同一輪多子問題不可合併）。
