# 102_R2_step3-qa.md

## 狀況理解

R2 使用者提出 4 個質問：(1) 三者的上下層概念關係 (2) 各自解決什麼問題與解法比較表 (3) DFlash 的 diffusion 應用在離散 token 上的合理性 (4) 三者在平行化/串列化上的異同。本 step 為品質保證階段，目標是將 R2 的調研結果沉澱進既有報告的 §5 User Q&A，並視需要補充 §1-§4。
