# 282_R1_step1-intent.md

## 狀況理解

- 本輪（R1）為新主題首次調研，非追問、非質疑。
- 技術標的：**Laya**（`NandhaKishorM/laya`，HF `convaiinnovations/laya`）——Jev／System 1 Model 的**開源復刻**。使用者提供了 GitHub、HF、影片（GitHub 一周熱點 132 期）與影片觀點，屬「技術名 → 分析 → 報告」工作流。
- 使用者附帶的關鍵脈絡（來自影片觀點，需在報告中被回應）：
  1. Jev 是「放棄自由生成、直接回傳結構化判斷」的 System 1 Model。
  2. 「快 20 倍／成本 1%／零幻覺」有場景限制——**格式保證正確、答案不保證正確**（選項只有 ABC 不會生 D，但正確是 A 時仍可能選 B）。
  3. Laya 發布的是**訓練決策模型的程式碼**，非 Jev 原版權重；提供 421M 英文、322M 多語言與決策微調版。
  4. 可 pip 安裝、下載權重本地調用、CLI 與 HTTP 服務接入。
  5. 作者自陳對照成績表中「某些任務比 Jev 快」的 Jev 數字取自**第三方結果**，雙方未在統一基準測試。
  6. 影片作者結論：價值在於**可下載、微調、部署並親手驗證「小模型負責判斷、大模型負責生成」**，換不換掉 Jev 不重要。
- 任務定調：對 Laya 做結構化技術解析，**輸出報告只回答五個固定點**（§1 解決什麼問題／§2 背景／§3 如何解決／§4 替代方案 DA 表／§5 留待 QA）。本輪為 R1，報告暫無 §5。
