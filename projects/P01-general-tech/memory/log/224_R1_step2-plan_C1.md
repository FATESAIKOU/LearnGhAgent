# 224_R1_step2-plan_C1.md

## 狀況理解

Step 1 已確認調研標的為 **1on1（一對一管理對談）作為管理手法**，來源是 SmartHR Tech Blog 文章（2026-08-13，チーフ山下）。使用者三問：①1on1 從作者觀點是「誰用的武器」②使用條件／預期效果／成本 ③為達相同目的的其他方案；且要求「全從原作者觀點出發，輔以大量參考資料」。

本 sub-step C1 依 document skill 標準動作執行。此標的**非 GitHub repo**，而是部落格文章，故以「抓取原文＋相關 SmartHR 文章＋背景脈絡」取代 gh repo view。C1 目標：取得原文全文、作者定位、SmartHR 制度背景、相關管理文章，供 C2 收斂成報告。

**關鍵技術事實（供 C2 收斂）：**
- **作者定位**：SmartHR 人給基幹プロダクト開発本部チーフ（プレイングマネージャー）山下，2024 年就任、2 年經驗。
- **制度背景**：SmartHR 制度上規定「評価者與被評価者隔週 1on1」；チーフ核心任務＝「チームの成果を最大化する」，1on1／評価皆為其手段。
- **作者三大スタンス**：①最終ゴール＝成員能氣持ちよく働ける（非教導／控制）②重視 icebreak（場的空氣影響本音）③定期讓成員評價 1on1 並改善（四半期一次）。
- **場的設計**：初回 1on1 與成員一起設計——「どんな時間だと嬉しいか」、目的確認調整（附たたき台）、アジェンダ整理、頻度時間設定（預設隔週 30 分）。
- **進め方**：icebreak 用「最近の調子 10 點滿分幾點」定型文；本題先確認成員持ち込みトピック，無則由チーフ提問（專案不安、納得度、對同事 feedback、欲求サポート）。
- **振り返り**：四半期一次，聚焦提問（モチベーション升降時機、想多談的、アジェンダ、頻度時間適切性）。
- **作者結論**：1on1 無絕對正解，但「兩人間有最適解」，靠定期振り返り與成員一起探索。
- **外部參考來源**：CEO 芹澤「1on1の功罪」、SmartHR Mag 1on1 系列、リクルートMS 個別最適 1on1、EM 文章（1on1 頻率分層與副作用）。
