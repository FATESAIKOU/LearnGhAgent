# 224_R2_step3-qa.md

## 狀況理解

R2 為追問輪，三問：①管理者在「掌握成員動機、不安、阻礙」此一目的上，除 1on1 外有無其他做法（質疑 R1 §4 未解說 1on1 目的與最優性）②後進資深員工（可能接管理）如何掌握周邊成員與上級狀態 ③把原文 1on1 技法收斂成表格。Step 2（C1）已取得 Q1 跨機制比較來源（skip-level／360／survey／觀察／coaching）與 Q2 準管理者視角來源（LeadDev skip-level 關係、managing up）。本 step 產出最終報告（追加 §5 User Q&A）與本 step 的 execution log。
