# 103_R1_step1-intent.md

## 狀況理解

使用者詢問「llama.cpp vllm 是啥, 用在哪」。這是 R1（首次請求），無前輪對話。技術標的有兩個：llama.cpp 與 vLLM。使用者不清楚這兩個專案的本質與應用場景，需要結構化調研，說明各自解決什麼問題、如何運作、以及使用情境。
