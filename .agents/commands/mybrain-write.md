# /mybrain-write

用 `mybrain-write` skill 把當前對話中值得長期保存的內容寫進 https://github.com/FATESAIKOU/MyBrain，開一個 PR 讓使用者 review。

這次要存什麼：`$ARGUMENTS`

沒指定就自己判斷這次 session 有什麼值得存；判斷後沒有值得存的就直接說明並停止，**不要開空 PR**。

`$ARGUMENTS` 含 `--dry-run` 時做到驗證為止，把打算寫的內容印出來，**不 push、不開 PR**。

**流程、該存什麼、寫作口吻、失敗處理全在那個 skill 裡，本檔不重複。**
